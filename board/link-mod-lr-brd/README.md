# link-mod-lr-brd

LoRa interface module of the **Link** platform. Plugged onto the base board,
it makes a Link-LR: a LoRa P2P radio on 868/915 MHz.

Part of [`link-hardware`](../../README.md). See the repository README for
naming, versioning and release conventions.

## Design

| Function | Part |
|---|---|
| LoRa radio | Seeed Wio-SX1262 module (Semtech SX1262, TCXO, RF switch) |
| Base interface | 2×10 header, 2 mm pitch |

The board is 60 × 50 mm. It carries the radio module and little else:
decoupling, pull-ups and the connector to the base. The antenna leaves
through a u.FL to SMA pigtail to the enclosure.

## Connectors

| Ref | Role |
|---|---|
| J2 | To the base board's J3: power (`+3V3`, `+VSYS`, `+VNR`), I²C and the eight module I/Os `IO_MOD01`–`IO_MOD08`, which carry the radio's SPI and control lines |
| J1, J3 | 1×8 sockets, 2.54 mm — not fitted on the Link-LR |

J2 mates with the base's J3, **the platform contract**: its pinout, the
mounting footprint and the 60 × 50 mm outline are what every interface
module must satisfy.

## Radio wiring

| Module I/O | SX1262 |
|---|---|
| `IO_MOD01` | MISO |
| `IO_MOD02` | SCK |
| `IO_MOD03` | MOSI |
| `IO_MOD04` | RF_SW |
| `IO_MOD05` | NRESET |
| `IO_MOD06` | NSS |
| `IO_MOD07` | DIO1 (interrupt) |
| `IO_MOD08` | BUSY |

The SX1262 drives the module's RF switch itself through DIO2, and powers
its TCXO through DIO3; neither pin leaves the module. The module's `RF_SW`
input must stay high for DIO2 to choose the direction: **R3 (10 k to
+3V3) holds it**, so the firmware leaves that pin alone.

## Status

Pre-production (`0.x`). Revision `0.2.0` is validated on our own bench; all
interfaces may still change without a MAJOR bump.

## Files

Design sources are the KiCad project in this folder. `outputs/` holds the
fab-agnostic exports of the last freeze — schematic PDF, BOM, position file,
gerbers and STEP.

They are regenerated by running `outputs.kicad_jobset` from the KiCad
project window. Output names carry the revision read from the schematic
title block, so they cannot drift from the sources.
